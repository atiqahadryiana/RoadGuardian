# Release notes

## 2026-10-25 — competition prototype repair and polish

### Added

- Restored the documented `app/` and `docs/` repository structure after the previous root files contained mismatched content.
- Added a complete no-login dashboard with five simulated scenarios, coherent junction state, operator event workflow, status/search filters, safe CSV export, persistence, and reset.
- Added a four-stage guided live demonstration showing how a synthetic roadside observation becomes a simulated operator event, with pause and replay controls.
- Added explicit simulated/mock labels throughout partial views, live action feedback, keyboard focus, skip navigation, reduced-motion support, responsive layouts, and print styles.
- Added a judge walkthrough, innovation canvas, product requirements, architecture, roadmap, and consolidated test plan.
- Added a local-only Python server with restrictive security headers and outbound connection blocking.

### Limitations

- No AI model, physical sensor, camera stream, personal data, geolocation, cloud, 5G network, emergency integration, or traffic control is connected.
- Risk states and latency are deterministic illustrative values, not predictions or measurements.
- Accessibility has implementation-level support but still needs testing with representative users and assistive technologies.
- Real deployment would require independent technical and safety validation, authority approval, security/privacy review, network measurement, and supervised field trials.
